# 基于AIGC的文创视觉氛围生成与风格化定制系统V1.0

著作权人：陕西理工大学
经办人 / 负责人：李果

## 运行环境

- Node.js 22 或更高版本，无需安装第三方依赖
- 浏览器需支持 Canvas 2D、SVG 与 ES Module
- 推荐分辨率 1920×1080，Chrome 或 Edge 最新稳定版

## 启动

```powershell
node server.js
```

默认地址：`http://127.0.0.1:4104`

可通过环境变量修改端口与数据目录：

```powershell
$env:PORT=4104
$env:DATA_DIR="E:\p04-data"
node server.js
```

## 初始账号

| 角色 | 用户名 | 初始密码 |
|---|---|---|
| 系统管理员 | admin01 | Admin@2026 |
| 专业设计师 | designer01 | Designer@2026 |
| 营销运营 | operator01 | Operator@2026 |
| 浏览者 / 客户 | viewer01 | Viewer@2026 |

首次登录后可在“个人资料”修改密码。上表为本地部署的初始化账号，不属于生产凭据；部署时应立即修改密码，并妥善保管`data`目录。

## 数据与文件

- `data/db.json`：业务数据，首次启动自动生成初始业务样本
- `data/uploads/`：生成结果与素材文件
- `data/secret.key`：登录令牌签名密钥，首次启动自动生成，不对外输出

备份时停止服务后复制整个`data`目录；恢复时用备份目录替换`data`后重新启动。

## 主要功能

- 专业设计师：生成任务创建与参数配置、风格与场景组合、结果预览与复用、色板提取与导出
- 营销运营：项目与素材浏览、审核提交、反馈处理
- 浏览者 / 客户：分享页查看、审核意见
- 系统管理员：账号管理、风格与场景维护、操作日志、系统设置、数据备份
