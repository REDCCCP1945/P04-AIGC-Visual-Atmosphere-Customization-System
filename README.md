# 基于AIGC的文创视觉氛围生成与风格化定制系统 V1.0

著作权人：陕西理工大学
经办人 / 负责人：李果

## 运行环境

- Node.js 22 及以上
- 浏览器：Chrome、Edge 或其他支持 SVG 与 Canvas 的现代浏览器
- 不依赖第三方 npm 包，不访问外网

## 启动

```bash
node server.js
```

默认监听 `127.0.0.1:4104`。可通过环境变量 `PORT` 指定端口，通过 `DATA_DIR` 指定数据目录。

## 目录结构

- `server.js`：服务入口，负责路由、鉴权、静态文件与限流
- `lib/`：认证、色彩规则、生成引擎、任务、资产、审核、设置等业务模块
- `public/`：前端页面、样式与视图脚本
- `data/`：运行时数据，首次启动自动生成，不随仓库发布

## 说明

软件为本地单机工具，生成结果为参数化 SVG，由本机完成，不调用外部模型或接口。首次启动会在数据目录生成 `db.json`、`secret.key` 与 `uploads/assets`，其中的账号与样本数据仅用于首次运行演示。
